# dotfiles

## Keybinding conventions

Each layer of the terminal stack uses its own modifier, so shortcuts never collide:

| Tool    | Modifier         | Scope                                   |
|---------|------------------|-----------------------------------------|
| Ghostty | `Super` (⌘)      | Terminal emulator: windows, tabs, splits |
| tmux    | `Ctrl`           | Sessions, windows, panes                |
| Neovim  | `Option` (⌥/Alt) | Editor; config in [paolosimone/nvim](https://github.com/paolosimone/nvim) |
